# Decision records

Why the product is built the way it is. A record carries the reasoning;
the code and its tests carry the behaviour.

**A record can be superseded.** When the decision changes, write the
replacement in the same pull request as the code that changes, and mark the
old one superseded so a reader lands on the live answer. A record that is
silently wrong is worse than no record.

New records continue from the highest number here. Take that number from
`origin/main` rather than from a branch — a stale branch shows a number as
free when somebody else has already taken it.

This file is generated by `scripts/gen-adr-index.sh`. Do not edit it.
